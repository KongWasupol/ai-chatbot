# 🤖 AI Chatbot

A simple AI chatbot built with OpenAI's GPT-4o-mini API and Streamlit.

## Features

- Real-time AI conversation
- Chat history within session
- Clean and simple UI

## Tech Used

- Python
- OpenAI API
- Streamlit

## How to Run

1. Clone this repo
2. Install dependencies: `pip install -r requirements.txt`
3. Add your OpenAI API key to a `.env` file: `OPENAI_API_KEY=your-key`
4. Run: `streamlit run app.py`
